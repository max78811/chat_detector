Создай телеграм бота который пользователь с телеграм премиум сможет
добавить к себе через бизнес функционал телеграма.

Бот должен уметь сохранять все измененые/удаленные сообщения из других личных чатов
в том числе видео и изображения

Tech stack:

- golang 1.26 version
- используй go migrate для миграций не храни миграции в коде они должны быть в корне проекта в папке migrations
- базу используй postgresql запущенную в docker compose
- также докерезируй самого бота
- так же сделай makefile который позволит отправить миграции или откатить их
- используй гексоганальную архитектуру при построении проекта
